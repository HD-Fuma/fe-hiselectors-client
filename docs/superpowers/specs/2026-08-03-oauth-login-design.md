# OAuth 신청 및 더현대 로그인 디자인

## 구현 경계

- 기존 React + TypeScript 클라이언트 안에서 화면과 로컬 선택 상태만 구현한다.
- 인증 SDK, API/네트워크 호출, 리다이렉트, 토큰·세션 저장, 자격 증명 검증은 구현하지 않는다.
- 모든 로그인/OAuth 액션은 `type="button"`이거나 폼 기본 동작을 막아 현재 해시 경로를 유지한다.

## 신청 폼 (`#/apply/form`)

- 기존 SNS URL, 핸들, 계정 ID 입력 필드는 모두 제거하고 단일 OAuth 버튼으로 대체한다.
- 소개 문구는 `본인 소유의 공개된 대표 SNS를 연결해주세요.`로, 개인정보 항목은 `② 수집 항목 : SNS 계정 연결 정보`로 바꾼다.
- 트리거의 초기 문구는 `대표 SNS 선택`이며 placeholder는 옵션이 아니다.
- 목록은 정확히 세 개만 이 순서로 표시한다: `인스타그램`, `페이스북`, `유튜브`. 다른 제공자는 표시하지 않는다.
- 선택 전 단일 버튼은 `SNS 계정 연결하기`이고 실제 `disabled` 상태다.
- 선택 후 같은 버튼이 활성화되며 각각 `Instagram 계정 연결하기`, `Facebook 계정 연결하기`, `YouTube 계정 연결하기`로 바뀐다.
- 다시 트리거를 열어 다른 SNS로 재선택할 수 있다.
- 트리거는 접근 가능한 이름과 `aria-haspopup="listbox"`, `aria-expanded`, `aria-controls`를 가진다. 옵션은 `role="option"`과 `aria-selected`를 가진다.
- Enter/Space로 열기, ArrowDown/ArrowUp으로 열기·이동, Enter로 선택, Escape로 닫기, 선택/닫기 후 트리거로 포커스 복귀를 지원한다.

### 신청 폼 치수

- 552px 패널, 좌우 16px 인셋, 트리거와 OAuth 버튼 높이 52px, 모서리 0px를 유지한다.
- 열린 메뉴는 트리거 바로 아래 1px 검정 테두리 안에 44px 옵션 세 줄을 배치한다.
- 메뉴는 아래 콘텐츠 위에 떠서 첨부 스크린샷과 같은 열린 상태를 만든다.

## 로그인 화면 (`#/login`)

첨부된 더현대Hi 로그인 스크린샷과 `https://hi.thehyundai.com/login?redirect=/mypage`를 시각 기준으로 삼는다.

1. `H.Point 통합회원 로그인`
2. 라벨이 연결된 아이디/비밀번호 입력; 비밀번호는 기본 `type="password"`
3. 상태에 따라 `비밀번호 보기`/`비밀번호 숨기기`로 이름이 바뀌는 버튼
4. `아이디 저장`, `자동 로그인` 네이티브 체크박스
5. 52px 검정 `로그인` 버튼과 우측 하단 초록색 `최근에 로그인 했어요.` 배지
6. `통합회원 가입하기`, `아이디/비밀번호 찾기`
7. 44px 외곽선 버튼 여섯 개를 정확히 다음 순서로 표시: `휴대폰 인증 로그인`, `네이버 로그인`, `카카오 로그인`, `토스 로그인`, `QR 코드 로그인`, `H.Point APP 로그인`
8. `BIZ회원 로그인` 제목, 안내문, `BIZ회원 로그인 페이지로` 버튼
9. `통합회원 전환` 제목, 안내문, `통합회원 전환하기` 버튼

로그인 콘텐츠는 552px 패널과 좌우 16px 인셋을 유지한다. 헤더 아래 상단 여백은 24px, 입력은 52px·간격 8px, 보조 버튼은 44px·간격 8px, 모든 컨트롤은 각진 흑백 테두리를 쓴다. 390px에서는 패널을 100%로 줄이고 세로 스크롤만 허용한다.

## 검증

- 신청 폼에서 정확히 세 옵션, URL/ID 필드 부재, 비활성→활성 OAuth 상태, 세 제공자별 라벨, 키보드 열기·이동·선택·닫기를 검증한다.
- 로그인에서 라벨 연결, 비밀번호 가시성, 체크박스, 정확한 여섯 버튼 순서, BIZ/전환 섹션, 모든 액션의 비이동성을 검증한다.
- 1894×963 데스크톱과 390×844 모바일에서 두 경로를 확인하고 `scrollWidth <= innerWidth`를 검증한다.
- 전체 Vitest 및 Vite production build를 통과한다.
